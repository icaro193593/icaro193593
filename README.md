## About Me

I am a **Student Researcher at Embrapa Gado de Leite** (Brazilian Agricultural Research Corporation) and a software engineer focused on bridging the gap between **computational biology, high-throughput genomic data, and scalable software architecture**. 

My work centers on designing and implementing distributed systems, asynchronous computing pipelines, and interactive web platforms for dairy cattle genomics (*Gir* and *Girolando* breeds) in partnership with Brazilian livestock breeding initiatives (e.g., PNMGL - National Dairy Gir Breeding Program).

* **Genomics & Statistical Genetics:** High-Density SNP Genotyping, Quality Control (QC), Linkage Disequilibrium (LD) Pruning, Genomic Ancestry Modeling (ADMIXTURE), and Single-Step Genome-Wide Association Studies (ssGWAS / BLUPF90 suite).
* **Relational Databases & SQL:** Design and administration of relational databases (**PostgreSQL**, **SQLite**), multi-schema database architecture, query optimization, indexing, and complex joins across millions of phenotypic, pedigree, and production records.
* **Network Storage & Infrastructure:** Deployment and administration of **Samba (SMB/CIFS)** network file shares to mount and expose high-capacity storage disks across lab servers, enabling seamless access to high-volume raw genomic files.
* **HPC & Distributed Systems:** Two-tier distributed architectures, asynchronous job scheduling (Redis Queue / RQ with concurrency locking), Systemd daemon management, and multi-core scientific execution.
* **Data Ecosystems:** Processing Illumina FinalReports, Neogen & Zoetis Clarifide commercial assay data, NCBI bovine genome annotations (ARS-UCD1.2), pedigree graphs, and publication-ready visualizations (Manhattan plots, FDR thresholds, stacked barplots).

### 1. BioLab — Cattle Genomics & Management Platform
![Private](https://img.shields.io/badge/Repository-Private-555555?style=flat-square) ![Embrapa Gado de Leite](https://img.shields.io/badge/Organization-Embrapa_Gado_de_Leite-005A9C?style=flat-square)
> **Comprehensive Cattle Genomics & Phenotypic Management Platform**

A full-stack genomic information system engineered in Django for dairy cattle breeding programs (*Gir* and *Girolando* breeds).

* **Multi-Schema SQL Architecture:** Uses structured multi-schema database models (PostgreSQL) to isolate breed-specific datasets while powering complex cross-table queries, dynamic filtering, and custom table joins.
* **Network Storage & Samba Integration:** Connects to centralized lab storage via **Samba (SMB/CIFS)** protocols (`smbclient`), enabling real-time synchronization and processing of high-volume raw sequencing and genotyping files directly from network disks.
* **Commercial Assay Ingestion:** Dedicated processing pipelines for **Zoetis Clarifide** and **Neogen GeneSeek (GGP)** chip data (`FinalReport`, `SNP_Map`, `Sample_Map`, and `iDats`).
* **Breeding & Phenotypic Analytics:** Integrates linear conformation scores, pedigree relationships, and official PNMGL dairy production records with automated diagnostic visualization.
* **Security & Multi-Tenancy:** Granular role-based access control (RBAC), user session auditing, and dynamic export pipelines.
* **Stack:** `Python 3.12`, `Django 6.x`, `PostgreSQL`, `SQL`, `Samba / SMBClient`, `Pandas`, `Matplotlib`, `Bootstrap 5`.

### 2. AdmixtureGen — Population Genetics & Ancestry Pipeline
![Private](https://img.shields.io/badge/Repository-Private-555555?style=flat-square) ![Embrapa Gado de Leite](https://img.shields.io/badge/Organization-Embrapa_Gado_de_Leite-005A9C?style=flat-square)
> **Automated Genomic Ancestry Inference & Population Structure Pipeline**

An end-to-end bioinformatic web suite that automates the transformation of high-throughput genotyping assays into quality-controlled population structure models.

* **Raw Assay Ingestion & Conversion:** Converts raw Illumina GenomeStudio and Neogen FinalReports into standardized binary PLINK formats (`.bed`, `.bim`, `.fam`), filtering for autosomal bovine chromosomes (BTA 1–29).
* **3-Stage Rigorous QC Pipeline:** Executes automated genotype call-rate filters (`--geno`, `--mind`), minor allele frequency thresholds (`--maf`), and Linkage Disequilibrium (LD) pruning (`--indep-pairwise 50 10 0.15`).
* **Multi-threaded ADMIXTURE Modeling:** Automates iterative population cluster inference ($K=2$ to $K_{max}$) with cross-validation (`--cv`), multi-threading, and automatic detection of the optimal $K$ value (lowest CV error).
* **Publication-Quality Visualization:** Generates publication-ready high-resolution stacked ancestry barplots with custom breed ordering, cross-validation error curves, and full ZIP bundle exports.
* **Stack:** `Python`, `Django 6`, `R`, `PLINK 1.9`, `ADMIXTURE`, `Polars`, `Matplotlib`, `ggplot2`.

### 3. Distributed ssGWAS Platform (Web Portal & HPC Compute Engine)
![Private](https://img.shields.io/badge/Repository-Private-555555?style=flat-square) ![Embrapa Gado de Leite](https://img.shields.io/badge/Organization-Embrapa_Gado_de_Leite-005A9C?style=flat-square)
> **High-Performance Distributed Single-Step Genome-Wide Association Study Infrastructure**

A two-tier distributed platform designed to orchestrate heavy statistical genetics pipelines across dedicated web and HPC compute servers.

**End-to-End Execution Workflow:**
* **1. Ingestion & Validation:** Users authenticate and upload phenotypic, pedigree, and genomic datasets through the containerized Django web portal (*Web Gateway Tier*), which validates inputs and ensures per-user directory isolation.
* **2. Asynchronous Dispatch:** The portal generates tailored parameter cards, securely transfers data files via SCP to the dedicated computing cluster (*Dedicated HPC Compute Node*), and enqueues analytical jobs through a Flask REST API managed by Redis Queue (RQ) with distributed concurrency locking.
* **3. HPC Statistical Execution:** Background workers orchestrate compiled Fortran 90 binaries from the **BLUPF90** suite (`renumf90`, `blupf90+`, `postGSf90`) to calculate genomic solutions, variance components, and SNP-level p-values.
* **4. Post-Processing & Automated Reporting:** The pipeline performs multiple testing corrections (FDR / Bonferroni via `statsmodels`), annotates top associations against NCBI bovine reference data (ARS-UCD1.2), plots publication-grade Manhattan diagrams, and packages results into timestamped ZIP bundles delivered back to the portal for download.

#### A. Web Gateway Tier
* **Multi-User Isolation:** Containerized Django gateway running behind Nginx SSL; isolates user datasets and parameters in dedicated sandboxes.
* **Parameter Card Generator:** Dynamic generation of parameter cards tailored to user phenotypic and pedigree specifications.
* **Automated Data Transfer:** Handles secure, synchronous SCP transmission of data files directly to the computing cluster.

#### B. HPC Asynchronous Compute Engine
* **Asynchronous Task Queue & Concurrency:** Microservices layer powered by Flask and Redis Queue (`RQ`) with distributed concurrency locking to guarantee race-condition-free executions across multiple users.
* **BLUPF90 Suite Orchestration:** Manages compiled Fortran 90 binaries (`renumf90`, `blupf90+`, `postGSf90`) compiled via Intel oneAPI for single-step GBLUP/GWAS solutions.
* **Statistical Rigor & Manhattan Plotting:** Automates multiple testing correction (Bonferroni & False Discovery Rate - FDR via `statsmodels`), generating publication-quality Manhattan plots from SNP solutions and p-values.
* **NCBI Annotation Ingestion:** Integrates automated fetching and parsing of bovine reference genome reports (`GCF_002263795.3` / ARS-UCD1.2) for candidate gene identification.
* **Stack:** `Python 3.12 (Flask, RQ)`, `Redis`, `Fortran 90 (BLUPF90 Suite)`, `Intel oneAPI`, `Docker Compose`, `Nginx SSL`, `Rocky Linux 9`, `Statsmodels`, `Matplotlib`.
